# QQMusicApi_HelperNext v0.2.0

First formal release of the component: the QQ Music capability core as a Rust
library, with a typed FFI surface and a line-based JSON stdio adapter over one
shared implementation.

## Compatibility

- Component: 0.2.0
- JSON protocol: 2
- BoltFFI: 0.31.0

## Supported release targets

- macOS ARM64 — stdio binary (`qqmusic-helper-next`)
- Android — BoltFFI, arm64-v8a / armeabi-v7a / x86 / x86_64

Windows, Linux, Apple FFI and wasm are not currently released or supported.

## Breaking / binding changes

- This is the first release, so there is no earlier release to be compatible
  with; 0.1.0-era local builds must adopt the Android set as a whole.
- Model fields are encoded positionally. Adopt the Kotlin binding, the JNI glue
  and the four ABI libraries **as one set** from this release; never mix them
  with artifacts from another revision.

## Added

- Protocol core: module/method/params, request envelopes, `web` and `android`
  platform profiles, `zzc` signing, device identity, credential persistence,
  rate limiting and circuit breaking.
- Ported domain endpoints (comments, MV, song assets, user relations,
  collection writes, recommendations, search extras, radio, favourites and
  more), with pagination offsets that count raw upstream rows rather than only
  the rows a caller can use.
- Word-level QRC lyrics with millisecond timing plus roma and kana; six-tier
  quality resolution with per-tier results.
- Typed FFI models and a stdio JSON adapter that share one endpoint
  implementation, so an embedded host and a spawned process behave identically.
- `qqmusic-helper-next --version`, which answers without any host
  configuration — the version smoke the release pipeline runs.

## Fixed

- Review findings from the Android integration: `wordLyric` returns `null`
  instead of a non-LRC document when QRC parsing yields no lines; `poll_login`
  freezes the configuration before touching storage; `set_liked_by_id` honours
  an explicitly requested platform; an imported encrypted UIN is stored
  trimmed.
