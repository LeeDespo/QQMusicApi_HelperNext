## 未实现的能力

### 私信（private_message）
- 状态：未实现（约 15 个方法，含发送 / 删除消息）
- 原因：依赖 Android 私信会话模型，原工作流未设计会话概念
- 完成条件：确定会话模型后按 `src/port/` 一领域一文件移植，并补真账号读写验证

### COS 上传（helper/init_upload、finish_upload、helper_utils）
- 状态：未实现
- 原因：需要分块、重试、上传状态与对象存储流程，原工作流未纳入
- 完成条件：设计上传状态机后移植，并用可牺牲的样本账号验证

### 手机客户端 MQTT 扫码
- 状态：未实现
- 原因：需要长连接与事件流，原工作流明确延期；历轮登录测试均按用户要求排除
- 完成条件：宿主确有扫码登录需求且获得授权后另行设计

## 未验证或缺少样本的边界

### 登录流程（微信 / QQ 扫码、手机验证码、凭据刷新）
- 状态：未验证；宿主保持现有 WebView 登录，未新增或测试扫码流程
- 原因：历轮验证均按用户要求排除登录与扫码
- 完成条件：取得可用环境并获得用户明确授权后，按 [testing.md](testing.md) 的规则测试

### 全量清空不喜欢歌曲
- 状态：仅验证获取 Token 的预检与离线参数 / 失败保护（缺失 Token 或非零业务码会阻止删除）；
  增删单个临时不喜欢条目已完整往返，未执行全量删除
- 原因：现有账号包含原始条目，全量清空会改变其时间与顺序
- 完成条件：拿到可牺牲的样本账号

### 指定用户的「我喜欢」
- 状态：已用当前账号的显式 `euin` 验证目标参数、解析与分页
- 原因：他人的公开主页及隐私限制没有额外账号样本
- 完成条件：第二个测试账号

### 内容可为空的分支（其他版本 / 附加歌词 / 乐谱）
- 状态：真实读取通过不代表每个分支都有非空样本；离线测试覆盖对应模型、解密与参数差异
- 完成条件：遇到非空样本时补 fixture

### 宿主 UI 与截图
- 状态：从未运行宿主 App UI 或查看截图
- 原因：不属于组件仓库的验证范围
- 完成条件：由宿主侧回归覆盖

### 其余写接口
- 状态：登录态写验证仅覆盖 `set_liked_by_id`（可逆写）与 2026-10-04 轮的歌单 / 收藏 / 评论契约；
  其余写接口未在真账号执行
- 原因：写接口一律需要明确授权、可逆与前后快照（见 [testing.md](testing.md)）
- 完成条件：逐个获得授权后按测试安全规则验证

- 完成条件与发布口径见 [RELEASING.md](RELEASING.md) §13。
