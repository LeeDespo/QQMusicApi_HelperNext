# 剩余范围与验证边界

本文件只记录**组件自身**尚未实现、尚未验证或缺少样本的范围。
已完成的一次性验证与接入取证归档在 [history/](history/)，历史材料不决定当前架构。

## 未实现的能力

### 私信（private_message）
- 状态：未实现。
- 原因：需要稳定的会话模型与安全验证方案。
- 完成条件：明确组件级契约后按 `src/port/` 的既有分层实现，并补受控验证。

### COS 上传（helper/init_upload、finish_upload、helper_utils）
- 状态：未实现。
- 原因：需要分块、重试、上传状态与对象存储流程。
- 完成条件：先定义上传状态机与失败恢复，再做实现和受控样本验证。

### 手机客户端 MQTT 扫码
- 状态：未实现。
- 原因：需要长连接与事件流，当前组件没有对应运行时模型。
- 完成条件：明确组件级需求、生命周期与安全验证环境后单独设计。

## 未验证或缺少样本的边界

### 登录流程（微信 / QQ 扫码、手机验证码、凭据刷新）
- 状态：端点存在，但真实登录流程未完成系统验证。
- 完成条件：取得可用测试环境并获得明确授权后，按 [testing.md](testing.md) 执行。

### 全量清空不喜欢歌曲
- 状态：只验证预检与离线失败保护；未执行真实全量删除。
- 原因：现有真实账号不适合作为破坏性样本。
- 完成条件：使用可牺牲测试账号，并满足可逆 / 前后快照要求。

### 指定用户的“我喜欢”
- 状态：已验证显式 `euin` 的参数、解析与分页；缺少更多账号 / 隐私边界样本。
- 完成条件：增加独立测试样本。

### 内容可为空的分支（其他版本 / 附加歌词 / 乐谱）
- 状态：真实读取通过不代表每个分支都有非空样本；离线测试已覆盖模型和参数差异。
- 完成条件：遇到稳定非空样本时补 fixture。

### 其余写接口
- 状态：只有部分写路径完成真实可逆验证；其余写接口不默认执行。
- 完成条件：逐项获得授权，并遵守 [testing.md](testing.md) 的写操作安全规则。

## 平台支持边界

- macOS ARM64 stdio 与 Android 四 ABI FFI 是当前正式 Release 目标。
- Apple typed FFI：可生成，但当前不作为正式 Release 资产。
- wasm：未适配、未验证，配置关闭。
- Windows / Linux：当前不发布正式可执行资产。

发布目标的权威口径只在 [RELEASING.md](RELEASING.md) 维护。
