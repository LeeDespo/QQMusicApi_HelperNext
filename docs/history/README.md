# 历史归档

本目录保存一次性验证报告、迁移/接入记录、审计快照和取证结果。

> **这里不是现行真源。** 历史材料按当时的代码、环境和外部依赖记录，允许随时间失效。
> 当前行为、架构、测试和发布规则必须回到仓库顶层活文档与生产代码确认。

查阅顺序：

- 当前架构与边界：[`../architecture.md`](../architecture.md)
- 当前公开接口：[`../endpoints.md`](../endpoints.md)
- 当前解析规则：[`../parsing.md`](../parsing.md)
- 当前测试规则：[`../testing.md`](../testing.md)
- 当前发布规则：[`../RELEASING.md`](../RELEASING.md)

历史报告可以引用已经删除的路径、旧版本、旧宿主状态或当时的研究资料；这些内容只用于解释
“当时发生了什么”，不得被新的实现或活文档依赖。需要把历史结论重新用于当前代码时，应先重新验证，
再把仍然有效的规则沉淀到对应活文档。
